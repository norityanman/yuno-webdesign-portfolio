# yuno-webdesign ロゴ一式

デザインの調査エッセンスは [`/company-logo/yuno-webdesign-logo.md`](../../company-logo/yuno-webdesign-logo.md) を参照。

## コンセプト

添付の手描きスケッチ（ひし形の中の「yd」モノグラム）を、直線と円弧だけで構成される
シンボルマークとして清書したもの。

- **ひし形（回転正方形）**：日本の家紋のような「囲み」の思想＋「想いをカタチにする」という
  ブランドコピーを重ねたモチーフ。
- **"Y" + "d" モノグラム**：左に、左右対称の2本の腕が中央で合流する"Y"（yuno）。右に、フルハイトの
  軸（ステム）にベジェ曲線の輪（ボウル）が沿う"d"（webdesign）。この2文字を横並びに配置し、
  それぞれが独立してひと目で判読できる形に整えている。
- **カラー**：輪郭＝ダークグレー `#333333`、モノグラムのストローク＝ミントグリーン `#4caf93`
  （既存サイトのメインアクセントカラーをそのまま踏襲）。

| ファイル | 用途 |
|---|---|
| `yuno-webdesign-mark.svg` | シンボルマーク単体（フルカラー）。favicon・SNSアイコン・名刺の一部などに。 |
| `yuno-webdesign-mark-mono.svg` | シンボルマーク単体（モノクロ／ダーク1色）。刻印・スタンプ・モノクロ印刷用。 |
| `yuno-webdesign-mark-white.svg` | シンボルマーク単体（白反転）。濃い背景・写真の上に載せる場合。 |
| `yuno-webdesign-logo-horizontal.svg` | マーク＋社名（横組み）。明るい背景用。ヘッダーなど横長スペースに。 |
| `yuno-webdesign-logo-horizontal-white.svg` | 横組みの白反転版。フッターなど暗い背景用。 |
| `yuno-webdesign-logo-stacked.svg` | マーク＋社名（縦組み）。名刺・SNSプロフィール・正方形バナー用。 |
| `png/` | 上記SVGから書き出した高解像度PNG（透過背景）。Officeソフトやフォント埋め込みが不安な印刷会社への入稿など、SVGを直接使えない場面向け。 |

| `business-card-preview.png` | 名刺デザインへの適用イメージ（表面／裏面のモックアップ）。**そのまま入稿するテンプレートではなく見え方確認用のプレビュー**。氏名等はサンプル。 |

## 書体

- ロゴタイプ：`Lora`（サイト本体の英字見出しフォントと同一）
- サブコピー："WEB DESIGN & BRANDING" は `Roboto`

## 使用上の注意

- SVGはすべてベクター形式のため、名刺サイズから看板サイズまで画質劣化なく拡大縮小できる。
- SVG内の `<style>` で Google Fonts（Lora / Roboto）を `@import` しているため、フォントを
  埋め込めない印刷ソフトで開く場合は `png/` 内の高解像度PNG（フォント形状を画像として焼き込み済み）
  を使用するか、印刷用データ作成時にテキストをアウトライン化すること。
- 最低使用サイズの目安：マーク単体は24px程度まで、横組みロゴは高さ32px程度まで視認性を確認済み。
