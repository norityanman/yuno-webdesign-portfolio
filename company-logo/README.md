「ロゴデザインのベストプラクティス」を調査した一次ソースの要点メモ。

- 著作権に配慮し、記事の全文転載は行わず「出典リンク＋要点の箇条書き」のみを保存している。
- ここでの調査から抽出したエッセンスは [`yuno-webdesign-logo.md`](./yuno-webdesign-logo.md) にまとめてある。
- このフォルダはロゴ制作の作業メモであり、サイト自体の成果物ではない（完成したロゴ本体は `/assets/logo/` を参照）。
