# yuno-webdesign ロゴ：調査エッセンスとデザインコンセプト

調査した一次ソース（[`./global/`](./global/), [`./japan/`](./japan/)）から抽出した普遍原則を、
yuno-webdesign というブランドの文脈に翻訳し、最終的なロゴデザインの仕様に落とし込む。

## 1. 調査から抽出した普遍原則（エッセンス）

| # | 原則 | 出典（要約） |
|---|------|------|
| 1 | **シンプルさが最優先** | 複雑な装飾を避け、極小サイズ（favicon・SNSアイコン）でも一瞬で判読できること。装飾よりも機能。 |
| 2 | **ベクター前提のスケーラビリティ** | 名刺サイズ〜看板サイズまで破綻しないよう、SVG等のベクター形式で設計する。 |
| 3 | **多用途性（バリエーション運用）** | フルロゴ／横組み／縦組み／アイコン単体／モノクロの最低5種を用意し、白黒でも成立させる。 |
| 4 | **幾何学的な骨格＋精緻なグリッド** | 円・正方形・ひし形・盾形などの図形にモノグラムを収めると「印章／エンブレム」的な一体感が出る。数学的な整合性が無意識の美しさを生む。 |
| 5 | **意味の裏付けがあること** | 「なぜこの形なのか」を説明できるロゴは説得力を持ち長く愛される。ブランドの理念・ストーリーを図形に翻訳するプロセスが重要。 |
| 6 | **時代を超える普遍性** | 一過性のトレンドを追わず、10年後も色褪せないデザインにする。 |
| 7 | **日本的な「囲み」の思想（家紋）** | 家紋はシンプルで強いシルエットを持ち、白黒だけで成立する。輪郭の中にモチーフを収める構成は、現代の幾何学モノグラムとも親和性が高い。 |
| 8 | **ネガティブスペースの活用** | 文字と文字の隙間・重なりに別の意味を持たせると、記憶に残る仕掛けになる（FedEx型）。 |

## 2. yuno-webdesign のブランド文脈

- **誰のためのブランドか**：個人事業主・小さな会社の"想い"に寄り添い、丁寧なヒアリングを通じて伝わるデザインに"カタチ"にするWeb制作会社（`index.html` のコピーより）。
- **既存デザイントークン**（`scss/_variables.scss`）
  - メインアクセント：ミントグリーン `#4caf93`（自然・誠実・成長）
  - セカンダリ：オリーブグリーン `#6b7d5f`（ナチュラル・落ち着き）
  - ワンポイント：マスタード `#e3b56c` / テラコッタ `#e8927c`（温かみ）
  - ベース：オフホワイト `#f7f4ee`、ダークグレー `#333`
  - 書体：見出し=明朝体「Shippori Mincho B1」／本文=「Noto Sans JP」／英字装飾=スクリプト体「Allura」／英字サブ=「Lora」
- **既存ロゴタイプの型**（`_header.scss`）：小文字「yuno」をアクセントカラー＋下線で強調し、「-webdesign」をダークカラーで続ける横組み。この"型"は維持し、そこに新しいシンボルマークを組み合わせる。

→ 上記より、**「手仕事の温かみ」「ナチュラルで誠実」「一目で分かるシンプルさ」「和のミニマリズム（家紋的な"囲み"）」** の4つを、今回のロゴが満たすべき軸とする。

## 3. 添付スケッチの読み解き → デザインへの翻訳

添付の手描きスケッチは、**ひし形（回転した正方形＝カイト型）の輪郭の中に、"y"と"d"が一本の連続した線でつながるモノグラム**（末尾に署名のような小さな渦の流れ）というアイデアだった。

これを「エッセンス」に沿って直線・曲線できれいに再構成する方針：

- **輪郭＝ひし形（回転正方形）**
  → 家紋的な「囲み」の思想（原則7）＋モノグラムを収める幾何学的な器（原則4）として採用。ひし形は「紙面が斜めに開く」「封筒の折り返し」「想いを折り込みカタチにする」というyuno-webdesignのコピー（"想いをカタチにする"）とも重なるモチーフ。正方形を45°回転させた正確なひし形にすることで、原則4の「精緻なグリッド」を満たす。
- **モノグラム＝"y"と"d"を一筆書き風の1本のリボン状ストロークで結合**
  → スケッチの「手描きで"yd"がつながっている」ニュアンス（丁寧に伴走する、想いをつなぐ）を活かしつつ、原則1・8に従い、直線と円弧・ベジェ曲線だけで構成し装飾的なブレを排除。"y"の払いがそのまま"d"のボウル（丸み）に流れ込む1本のストロークとして設計し、単独のシンボルとしても、favicon・SNSアイコンの極小サイズでも判読できるシンプルな形に整える。
- **配色**：ストロークはメインアクセントのミントグリーン `#4caf93`、ひし形の輪郭はダークグレー `#333`（または単色バリエーションとしてミントグリーン統一版）。白黒１色でも成立するよう、輪郭線と塗りのコントラストだけで形が破綻しないシルエットにする（原則3・7）。
- **ロゴタイプとの組み合わせ**：既存の "yuno"（ミントグリーン太字＋下線）＋"-webdesign"（ダークグレー）の型をそのまま活かし、マークを左または上に配置する横組み／縦組みの2レイアウトを用意する（原則3）。

## 4. 最終仕様

- **シンボルマーク**：45°回転の正方形（ひし形）フレーム＋"y→d"一筆書きモノグラム。100×100のグリッド上に、線幅・余白を統一して設計。
- **カラー**
  - フルカラー版：ひし形の輪郭＝ `#333`、モノグラムのストローク＝ `#4caf93`（グラデーションで一部 `#6b7d5f` を差し込み、奥行きを出す）
  - モノクロ版：`#333` 1色（または白1色の反転版）
  - 白反転版（フッターなど暗背景用）：`#fff` ベース＋モノグラムに `#cdeee0`（淡いミント）のアクセント
- **書体**：ロゴタイプ部分は既存踏襲で「yuno」＝Lora風の太字＋ミントグリーン下線、「-webdesign」＝Shippori Mincho B1 寄りのダークグレー。
- **バリエーション（`/assets/logo/` に格納）**：
  1. マーク単体（アイコン・favicon用）
  2. マーク＋ロゴタイプ 横組み（通常カラー）
  3. マーク＋ロゴタイプ 横組み 白反転版（暗背景用）
  4. マーク＋ロゴタイプ 縦組み（名刺・SNS用の正方形レイアウト）
